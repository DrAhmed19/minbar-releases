# منبر — تطبيق أندرويد

قصائد ولطميات الرادود باسم الكربلائي، مع الكلمات المتزامنة.

## التحميل

- **أغلب الهواتف:** [تحميل منبر](https://github.com/DrAhmed19/minbar-releases/raw/main/minbar.apk)
- **الهواتف القديمة (32-bit):** [تحميل منبر](https://github.com/DrAhmed19/minbar-releases/raw/main/minbar-arm32.apk)

بعد التحميل افتح الملف واسمح بـ«التثبيت من مصادر غير معروفة» إذا طلب الهاتف.
التطبيق ينبّهك تلقائياً عند صدور نسخة أحدث.
